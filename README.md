
# Customer Churn Prediction using Machine Learning

## Project Status

> **This is an ongoing project.**
> The model pipeline, feature engineering, and hyperparameter tuning are still being actively developed. While the current implementation provides a solid baseline, there is considerable scope for improving predictive performance through further experimentation, advanced feature engineering, model optimization, and ensemble techniques.

---

## Overview

Customer churn is one of the most critical business challenges across industries such as banking, telecommunications, insurance, and subscription-based services. Predicting customers who are likely to leave enables organizations to take proactive retention measures, ultimately reducing revenue loss and improving customer satisfaction.

This project applies supervised machine learning techniques to predict whether a customer is likely to churn based on demographic, financial, and behavioral attributes.

---

## Objective

* Analyze customer behavior through Exploratory Data Analysis (EDA)
* Identify the most influential features affecting churn
* Handle class imbalance using SMOTE
* Compare multiple machine learning models
* Optimize model performance through feature engineering and hyperparameter tuning
* Build a reproducible ML pipeline
